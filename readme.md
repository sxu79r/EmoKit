## ✨ 核心功能
- **快速保存表情**：支持拖拽或选择图片文件，快速添加到本地表情库。  
- **标签管理**：为每个表情添加自定义标签，方便分类和检索。  
- **快捷键调用**：支持自定义全局快捷键，快速唤起表情选择窗口。  
- **表情检索**：通过关键字或标签快速搜索所需表情。  
- **一键复制**：点击表情即可复制到剪贴板，支持多种聊天平台使用。  
- **分组与分类**：按主题或用途分组，界面清晰，管理便捷。  
- **轻量易用**：简洁界面，低资源占用，操作直观。

## 🛠技术栈
- **语言**：Python 3.x  
- **GUI 框架**：PyQt5 + QFluentWidgets  
- **数据库**：SQLite（本地存储表情和标签）  
- **快捷键支持**：keyboard 库
  
## 📖 使用说明

## 📦安装与运行
### 方式一：源码运行
1. 克隆项目到本地：
   ```bash
   git clone https://github.com/yourusername/quick-emoji-manager.git
   cd quick-emoji-manager
   ```
2. 创建虚拟环境（可选）：
   ```
   conda create -n emoji_env python=3.10
   conda activate emoji_env
   ```
3. 安装依赖：
   ```
   pip install -r requirements.txt
   ```
4. 运行程序：
   ```
   python main.py
   ```
### 方式二：使用打包好的 exe

下载 [Releases](https://github.com/sxu79r/Emokit/releases)
 中的 zip文件。

解压

双击运行EchoBi.exe，无需安装 Python。
